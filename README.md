## Objetivo del Proyecto

Este sitio web es un espacio **minimalista y optimizado** diseñado para proyectar mi perfil profesional en el ámbito del desarrollo de software. Su propósito es exponer mis conocimientos técnicos, metodologías de resolución de problemas, proyectos de alto impacto y mi entusiasmo por la automatización de procesos.

> [!NOTE]
> En este portafolio priorizo la honestidad y la claridad: explico con mis propias palabras cómo abordo los desafíos técnicos y muestro evidencias reales de mi trayectoria.

## Estructura y Apartados Clave

| Apartado | Enfoque Principal | Lo que descubrirás aquí |
| :--- | :--- | :--- |
| **Sobre Mí** | Perfil y Metodología | Mi enfoque ante problemas complejos, cómo investigo a fondo cuando me estanco y cómo integro **Agentes de IA** y automatizaciones para acelerar flujos de trabajo. |
| **Experiencia** | Soluciones e Impacto | Problemáticas reales que he resuelto, métricas de impacto en empresas, documentación técnica (`README`) y réplicas de software con ejemplos fuera del ámbito laboral. |

| **Contacto** | Conectividad | Canales directos para agendar citas (virtuales o presenciales) y llamadas a la acción para reclutadores o clientes interesados. |

## Instalación y Desarrollo Local

Si deseas clonar este portafolio y ejecutarlo en tu máquina:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com
   cd tu-repositorio
   ```

2. **Instala las dependencias:**
   ```bash
   npm install
   ```

3. **Inicia el servidor de desarrollo (Vite):**
   ```bash
   npm run dev
   ```
